# CarDeck 版本说明

版本号规则：`YYMMDD` + 当日序号，与 `app/AndroidManifest.xml` 的 versionCode/versionName 一致。

## v2611230（2026-11-28）

- 普通口令 `Nopass` 进设置页后底部多了「退出设置」：点了洗掉本次解锁状态、直接回首页。
- 高级口令 `nopass123` 的维护块同样有「退出设置」，与「立即重新上锁」并列（一个回首页，一个回口令门）。
- `build.ps1` / `publish-update.ps1` 去掉写死盘符，改成按脚本自身位置取工程与输出目录。

## v2611229（2026-11-21）

- 首页四句「观世事　悟本质／思有度　行有距」可在普通设置页（口令 `Nopass`）里改：四格输入，逐句替换。
- 只换文字，字号、字重、字距、行高、银色拉丝渐变、全角空格与换行位置全部沿用原样；实测 62px / 6px / 71.92px 与改前一致。
- 存储走独立键 `cardeck.creed`，不动 `cardeck.settings`；留空的句子按默认文字显示，另有「恢复原文」。
- 高级口令 `nopass123` 页面看不到这一块（与其他普通面板同属 `std-only`）。

## v2611228（2026-11-21）

- 修复：全球新闻详情页「🔊 朗读」在 APK 内无声。
- 新增原生 TTS 桥 `TtsBridge`，注册为页面里的 `window.QsisTTS`（接口 `speak/stop/status`），中文 `zh-CN`、英文 `en-US`；引擎初始化未完成时排队，就绪后补播。
- `AndroidManifest.xml` 增加 Android 11+ 包可见性 `<queries>`：`android.intent.action.TTS_SERVICE`，否则查不到系统朗读引擎。
- `MainActivity` 注册桥并在 `onDestroy` 释放引擎。
- 服务端新闻页 `/www/news/news_detail.php` 未改动（它本来就优先调用 `window.QsisTTS`）。
- 装机自检：新闻详情页长按朗读按钮，标题显示「本机 TTS：就绪」即生效。
